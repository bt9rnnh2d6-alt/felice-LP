# 3Dモデル部品の追加方法（Felice オーダーシミュレーター）

シミュレーターは `assets/models/` 配下の **GLBモデル部品** を読み込み、段の積み重ね・装飾配置・トッパーを組み合わせて表示します。
**GLBファイルを置いて、登録コマンドを1回実行するだけ**で部品が増えます。

---

## 1. ファイル形式

- **`.glb` を推奨**（テクスチャ込みの単一ファイル。`.gltf`＋テクスチャでも可）。
- **1部品＝1ファイル**。完成品まるごとではなく、苺・お花・段…など部品単位で。
- **Draco圧縮はオフ**でエクスポート（このビルドは未対応のため）。
- Web表示用に **1部品あたり数万ポリゴンまで** を目安に。

## 2. 置き場所（カテゴリ＝フォルダ）

| フォルダ | 用途 | 例 |
|---|---|---|
| `assets/models/tier/` | 段（土台）※必須 | `round.glb` |
| `assets/models/berry/` | 苺・ベリー類 | `strawberry.glb`, `blueberry.glb` |
| `assets/models/flower/` | お花・グリーン | `rose.glb` |
| `assets/models/macaron/` | マカロン・焼菓子 | `macaron.glb` |
| `assets/models/ribbon/` | リボン・ボウ | `bow.glb` |
| `assets/models/topper/` | トッパー | `topper.glb` |
| `assets/models/pearl/` | パール | `pearl.glb` |

## 3. 向き・原点・サイズの取り決め

- **Y-up**（glTF標準。Blenderの glTF エクスポートは自動でこの向き）。
- **原点＝底の中心（接地点）**。装飾はテーブルに置いたときの底、段は下面の中心。
- **サイズは適当でOK**。読み込み時にこちらで自動正規化します（`manifest.json` の `size` で微調整可）。

## 4. 追加・差し替えの手順

1. 上表のフォルダに `.glb` を置く（既存と同名で置けば差し替え）。
2. 登録コマンドを実行（マニフェスト再生成）:
   ```
   python3 assets/tools/gen_manifest.py
   ```
3. シミュレーターを再読み込み。

> 表示名は `gen_manifest.py` の `NAMES` 表で日本語化しています（未登録のIDはファイル名がそのまま表示）。
> 例: `strawberry`→苺, `blueberry`→ブルーベリー, `rose`→バラ, `macaron`→マカロン, `bow`→リボン, `pearl`→パール。
> 新しい部品名を足したい場合は `NAMES` に1行追加してください。

## 5. プレビュー方法（重要）

GLBは `fetch` で読み込むため、**`file://` で直接開くと表示されません**。付属の簡易サーバーで開いてください。

```
python3 サーバー起動.py
```
→ ブラウザで `http://localhost:8080/simulator.html`

## 6. 現状

- いまは動作確認用の **ダミーGLB**（簡易形状）が入っています。
- 本番の `.glb` を同じパスに置いて `gen_manifest.py` を実行すれば、そのまま実物の部品に差し替わります。

---

### 付録：Blenderからのエクスポート設定（参考）
`ファイル > エクスポート > glTF 2.0 (.glb)` → フォーマット **glTF Binary (.glb)** /
**+Y Up** 有効 / **Compression(Draco) オフ** / 必要なら「選択physオブジェクトのみ」。
書き出し前に **原点を底の中心** に（オブジェクト > 原点を設定）。
